## Why this set is held out

Delivery 001 was built from **31 Aug – 6 Sep**. This set is the week *before*, deliberately, because Claude picked Delivery 001 and cannot also grade it.

**This is not a training set, and the system does not learn from it.** No weights, no feedback loop, no personalisation. It answers one question, once:

> Does any ranking beat plain reverse-chronological order at picking five things worth Barbara's attention?

D-11 says that if the answer is no, the prioritisation layer gets **deleted**, and deleting it counts as a good outcome. So this set exists to give a ranker something to fail against. A learning system would use these labels to get better; this uses them to decide whether the ranker should exist at all.

If Barbara later wants a system that adapts — the interest profile under D-10, taught by the "less like this" signal — that is a separate mechanism, and it would need its own held-out set to prove it improved anything. Do not conflate the two.

1. **Label first, before any ranker output is visible.** For each item below, mark `Y` (worth one of five slots) or `N`. No middle value; the cap forces a binary.
2. **Write the threshold down before comparing.** Fill in the blanks below and commit them. A threshold chosen after seeing results is not a threshold.
3. **Baseline:** the five most recent items at delivery time — reverse chronological, no judgment. Computable from the dates here.
4. **Compare.** Ranker top five versus baseline top five, scored against the labels.
